Docker Under Cursor / 在光标位置显示面板

Version / 版本：2.0

Use keyboard shortcuts to show Krita dockers at the cursor position.

通过快捷键将 Krita 面板浮动显示在光标位置。

Usage

  1. Open Tools → Scripts → DUC Settings panel.
  2. Select the dockers you want to control and click Save.
  3. Restart Krita to load the selected docker actions.
  4. Open Configure Krita → Keyboard Shortcuts → Scripts → Docker Under Cursor and assign shortcuts.
  5. Press a docker's shortcut to show it at the cursor. Press it again to hide it or return it to its docked state.

Shortcut entries use Krita's internal docker names. Pinning and canvas-only actions are listed under Docker Under Cursor Other.

使用方法

  1. 打开工具 → 脚本 → DUC Settings panel。
  2. 勾选需要控制的面板，点击 Save。
  3. 重启 Krita，加载所选面板的快捷键动作。
  4. 打开配置 Krita → 键盘快捷键 → Scripts → Docker Under Cursor，为各面板分配快捷键。
  5. 按下面板快捷键，在光标位置显示面板；再次按下，则将其隐藏或停靠回主窗口。

快捷键条目使用 Krita 内部的面板名称，可参考下方对照表。固定面板和切换画布模式的动作位于 Docker Under Cursor Other 分类中。

Options / 行为选项

Remember mouse position relative to docker
Reuse the cursor's relative position when showing a docker; otherwise, center the docker on the cursor.
记住光标在面板内的相对位置；关闭后，面板中心将对齐光标。
Keep docker inside the main window
Constrain the floating docker's position to the main window.
将浮动面板的位置限制在主窗口内。
Auto conceal docker after mouse leaves
Return or hide the floating docker when the cursor leaves it.
光标离开浮动面板后，自动还原或隐藏面板。

These options apply when you click Save. Changes to the enabled dockers require a restart.

上述选项在点击 Save 后立即生效；修改启用的面板列表后，需要重启 Krita。

An asterisk (*) in the window title indicates unsaved changes. Saving clears it and keeps the window open. A yellow message appears at the top if saved docker actions are not yet fully registered in Krita.

窗口标题中的星号（*）表示有未保存的更改。保存后星号消失，窗口保持打开。如果已保存的面板动作尚未全部注册到 Krita，窗口顶部会显示黄色重启提示。

Generated shortcut definitions are saved as actions/dockerundercursor.action inside Krita's resource directory.

生成的快捷键定义保存在 Krita 资源目录下的 actions/dockerundercursor.action 中。

Pinning and canvas-only mode / 固定面板与画布模式

Hover over a floating docker and press Ctrl + backtick (`) to pin or unpin it. A pinned docker's shortcut moves it between its pinned position and the cursor.

To preserve pinned dockers when switching canvas-only mode, assign Tab to DUC only canvas mode and remove any conflicting assignment.

将光标移到浮动面板上，按 Ctrl + 反引号（`） 可固定或取消固定面板。固定后，面板快捷键会让它在固定位置和光标位置之间切换。

若要在切换画布模式时保留固定面板，可将 Tab 绑定到 DUC only canvas mode，并移除冲突的绑定。

Known issues / 已知问题

Dockers with scroll bars may shrink after repeated floating and docking. Float the docker, then manually drag it back into the main window's docking area to restore its size.

带有滚动条的面板在反复浮动和停靠后，高度可能变小。将面板浮动后，手动拖回主窗口的停靠区域，即可恢复正常尺寸。
